# Week 9: Dashboard workshop

This week is a dashboard workshop. The focus is on bringing together Shiny skills from the previous weeks and shaping them into an assessment-ready dashboard structure.

The session supports planning, building order, reproducibility, and dashboard design. You will work on a practical dashboard task and use checklists to evaluate whether the app is clear, functional, and appropriate for portfolio work.

By the end of Week 9, you should be able to:

- define a realistic dashboard scope for the assessment,
- plan a practical build order,
- organise app controls and outputs clearly,
- check that an app is reproducible and understandable,
- identify optional extensions without overcomplicating the dashboard.
