# Week 9: Turn questions into a dashboard

We will briefly try Plotly hover and zoom, then spend most of this session adapting a dashboard to behavioural data and a useful question. You will choose two complementary views, purposeful controls and clear explanations, then test that they work together.

Unzip the whole Week 9 folder into your existing module project and keep data/ beside the scripts. Knit `01_plotly_and_dashboard_workshop.Rmd` first. Read the HTML guide and edit `plotly_app.R` for the short Plotly task, then `starter_app.R` for the workshop. If needed, install Plotly once using the guide's installation chunk.

Bring your proposed summative data if ready. It is fine to use the provided participant-level practice extract if you are still choosing data. The guide gives three question options and instructions for both routes. Completed examples are introduced at the end.

Aim to leave with a working two-view prototype and notes explaining a design decision. After class, continue your own-data app and bring specific questions to Session 10, when we will practise reproducibility and submission checks.
