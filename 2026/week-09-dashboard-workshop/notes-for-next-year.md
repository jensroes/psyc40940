# Week 9: notes for next year

Recorded on 24 November 2026.

Start the summative workshop by creating or checking a dedicated assessment RStudio project, before importing data or building an app. Copy only the relevant files into it. Keep `app.R` and the report Rmd beside the `.Rproj` file, with actual data in `data/`. This lets Console checks, report knitting and Run App use the same `data/...` paths and avoids the confusion caused by an app in a nested folder needing `../data/...`.

Build this organisation into Week 9's opening instructions and examples, rather than first introducing it in Week 10. Keep the original weekly work as a backup. A student without a dataset can practise with the supplied data in the same simple layout, then adapt the pattern to their own chosen summative dataset.

Students who missed the previous session should start with project organisation, load their own or the supplied data into the Week 9 app template, get one ordinary ggplot working, then put it inside the matching render block. Only after that should they connect controls and shared reactive filtering. The catch-up route should be explicit in the session guide and use the same files and naming conventions as the main workshop.
