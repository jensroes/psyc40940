Assignment Instructions

The purpose of this formative mini-portfolio is to scaffold your learning and provide feedback before the summative portfolio.

Select a behavioural dataset, meaning data related to human behaviour such as psychological experiments, survey responses, reaction times, decision-making patterns, or social media behaviour.

  • Create 3-4 visualisations using different techniques, such as a boxplot, scatterplot, or density plot.
  • Include brief commentary on what each visualisation highlights about the data.
  • Explain why each visualisation was chosen.
  • Explain how each visualisation adheres to principles of effective visualisation, such as Tufte's guidelines.
  • Comment on the extent to which each visualisation may or may not obscure the data.

Use RMarkdown for the report. GitHub is optional. Relevant tools include ggplot2 and plotly.

Submission Requirements: Dropbox Submission

Submit a single zip archive to the NOW Learning Room Dropbox before 2 pm on the deadline day. Ensure that you receive and keep the email confirming submission.

The zip archive must contain exactly one RMarkdown file, the HTML or PDF document generated from this file, the RStudio project file, the relevant data file, and any supplementary files such as bibliography files or custom R functions.

The work must be reproducible from the RMarkdown source code and other files you provide. All R code should be contained in the RMarkdown file and should reference the relevant data files.
