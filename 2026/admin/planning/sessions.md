# 2026 Session Folders

Each teaching week has a self-contained folder with root-level slide decks, exercises, data, graphics, and supporting files needed for that session.

| Week | Folder | Contents |
|---|---|---|
| 1 | `week-01-introduction` | Module introduction, R/RStudio setup, and RMarkdown introduction |
| 2 | `week-02-foundations` | Principles of data visualisation and ggplot2 exercises |
| 3 | `week-03-grammar-of-graphics` | Grammar of graphics slides and exercises |
| 4 | `week-04-major-visualisation-tools` | Visualisation types, group comparisons, data wrangling |
| 5 | `week-05-customising-visualisations` | Labels, colours, themes, and figure sizing |
| 6 | `week-06-shiny-basics-reactivity` | UI/server, inputs/outputs, automatic updates and app explanations |
| 7 | `week-07-reactivity-layouts` | Shared reactive data, count text, complementary plots and sidebar |
| 8 | `week-08-tabs-controls` | Core tabs, control choices, group/range filters and empty-selection feedback |
| 9 | `week-09-dashboard-workshop` | Plotly introduction, data/question transfer and a purposeful dashboard prototype |
| 10 | `week-10-wrap-up-assessment-support` | Separate report/app structure, extracted-ZIP checks, reflection and support |

The older source-style folders are retained in `_source/` as working sources. The `week-*` folders are the Learning Room-facing structure. Slide decks are stored at the week-folder root and share a single `slides.css` file per week.
