# Week 3: Grammar of graphics

This week introduces the grammar of graphics and how it underpins `ggplot2`. We will focus on how plots are built from data, aesthetic mappings, geometries, statistical transformations, coordinates, facets, and themes.

The practical work asks you to build plots step by step and to distinguish between aesthetics that are mapped to variables and attributes that are set directly.

By the end of Week 3, you should be able to:

- explain the main components of the grammar of graphics,
- build `ggplot2` plots from data, aesthetics, and geometries,
- distinguish mapped aesthetics from fixed attributes,
- use facets and other plot components to show structure in behavioural data,
- read `ggplot2` code as a layered description of a figure.

## Before the practical work: RStudio Project and weekly files

All practical files should be stored inside your module RStudio Project folder. Do not work inside the zip file.

If you have not created an RStudio Project for this module yet:

1. Open RStudio.
2. Go to **File > New Project...**.
3. Choose **New Directory**.
4. Choose **New Project**.
5. Give the project a clear name, for example `psyc40940-visdata`.
6. Choose a sensible location on your computer.
7. Click **Create Project**.

Then download the Week 3 zip folder from this week's section in the NOW Learning Room, unzip it, and move the contents into your module RStudio Project folder. Keep the `.Rmd` files or app files together with any `data` folder and supporting files.
