# Week 7: Shiny layout and observers

This week develops the Shiny work by focusing on app layout and observers. We will look at how to organise dashboards using sidebars and tabs, and how to control when app outputs update.

The practical work combines layout choices with observer patterns so that apps become clearer for users and easier to control.

By the end of Week 7, you should be able to:

- organise Shiny apps using common layout structures,
- use sidebars and tabs to separate controls and outputs,
- distinguish automatic reactive updates from controlled updates,
- use observers for simple app behaviour,
- combine layout and observer logic in a small dashboard.

## Before the practical work: RStudio Project and weekly files

All practical files should be stored inside your module RStudio Project folder. Do not work inside the zip file.

If you have not created an RStudio Project for this module yet:

1. Open RStudio.
2. Go to **File > New Project...**.
3. Choose **New Directory**.
4. Choose **New Project**.
5. Give the project a clear name, for example `psyc40940-visdata`.
6. Choose a sensible location on your computer.
7. Click **Create Project**.

Then download the Week 7 zip folder from this week's section in the NOW Learning Room, unzip it, and move the contents into your module RStudio Project folder. Keep the `.Rmd` files or app files together with any `data` folder and supporting files.
