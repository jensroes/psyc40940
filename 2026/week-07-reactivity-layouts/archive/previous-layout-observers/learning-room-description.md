# Week 7: Shiny layout and observers

This week develops the Shiny work by focusing on app layout and observers. We will look at how to organise dashboards using sidebars and tabs, and how to control when app outputs update.

The practical work combines layout choices with observer patterns so that apps become clearer for users and easier to control.

By the end of Week 7, you should be able to:

- organise Shiny apps using common layout structures,
- use sidebars and tabs to separate controls and outputs,
- distinguish automatic reactive updates from controlled updates,
- use observers for simple app behaviour,
- combine layout and observer logic in a small dashboard.
