# Practice project: Dutch sentence production

This is a runnable reproduction exercise, not a portfolio to submit. Open portfolio.Rproj, knit report.Rmd, then use Run App on app/app.R. Stop the app before knitting again.

The report reads data/participant_rates.csv and data/production_trials.csv from the project root. The app reads ../data/participant_rates.csv from its app folder. Keep both files and data/README.md, the bibliography and project file together. The source study is van Lieburg et al. (2023); the dictionary links to the article and OSF files and explains the supplied preparation.

Each summary row is one learner, session, prompt condition and phase. The first three report figures and app plots use counts of full passive responses out of four target trials (0–4); the report's response-composition bars show proportions across all response categories. The same people appear repeatedly. Missing occasions are not zero, and descriptive change does not isolate a causal intervention effect.

The report renders four static techniques with captions, a cross-reference, citations, inline calculated counts and package-version information. The app explores average and individual patterns. All code is complete, but commentary and reflection prompts remain for teaching; this is not a finished assessment narrative. Write your own submission around your own justified data and questions.

Test an extracted ZIP in a fresh R session. Required report packages are tidyverse, rmarkdown and bookdown; the app loads shiny and tidyverse independently. AI declarations must be completed using the actual NOW form; no fabricated declaration is supplied in this example.
