Practice portfolio: change in Dutch sentence production

Purpose and data

This is a reproducibility practice example, not a model assessment answer. The code is complete so the report can be rendered from an extracted project. You supply the interpretation and reflection; the example is not a portfolio to submit.

The teaching extract comes from the longitudinal sentence-production experiment reported by Lieburg et al. (2023). Active and passive sentences are alternatives, not incorrect and correct answers. Each summary row represents one learner, one study session, one prompt condition and one phase, combining four recorded target trials. The same people appear repeatedly. The trial-level file is supplied so the summaries can be traced and response categories examined.

The baseline subset includes 17 learners in 164 summary rows. The first three figures use the number of full passive responses out of four recorded target trials in each cell (0–4). Other responses and no response remain among those four trials. The average across learners can be fractional. This differs from the article’s main binary analyses, which exclude those categories. It is not a reproduction of the published percentages or statistical models. See data/README.md for coding, source and preparation.
