## Catch-up routes

All students begin with the assessment-project task. Those with no working app but with a dataset use own_data_app.R, an unchanged copy of the Week 9 template, load their data and get one plot working in its first render block. Those with neither an app nor data use supplied_data_template.R, the Week 9 supplied-data template, with the prepared CSV and the guide's first-plot completion. Both then join the controls task. supplied_data_app.R remains a one-plot reference/fallback; the full worked_example_app.R is for comparison after an attempt. The guide keeps catch-up instructions collapsed, so continuing students can proceed directly to their next connection.

Exercise 1 is explicitly framed as resolving Week 9's path/data-loading problems: Console checks and Run App sometimes started from different folders. Organising the app, report and project together gives the import code one consistent starting point before students add controls.

AI coding support is optional within the existing workshop time. A short slide and collapsed prompt show students how to use distinct(data, variable) to obtain the variable name and observed values. They copy the command/output and current app code, then ask how and where to add one control in the UI/server. The prompt requests a brief explanation; students read and test the changes. This follows the brief's AMBER allowance for code support; submitted commentary, interpretation, design rationale and reflection remain the student's own work and use must be declared.
