# Week 10: Reproduce and review your portfolio

The practice project now continues Week 9's Dutch sentence-production study. It includes participant_rates.csv and production_trials.csv, the documented all-trial denominator, source citation and a separate app. The four static techniques are a mean-change plot, boxplots with points, an individual heatmap and response-composition bars. Source code is hidden by default; inline R demonstrates calculated narrative counts. This remains a reproducibility exercise, not a model assessment answer.

Core material: a short slide set, `session-guide.html` (open in a browser), and submission-example/, a runnable project with one report Rmd, four example static plot types, bibliography, data, and separate `app/app.R`.

Students use their own project for the extracted-ZIP exercise if ready, or practise with the example. The complete example is a reproducibility aid, a teaching example rather than a model assessment answer.

The report reads data/ from its project root; the app reads ../data/ from its app folder. Test both in a fresh extracted project. Report setup uses tidyverse and bookdown::html_document2; the app uses shiny and tidyverse.

First 50 minutes: four-figure/two-app-view plan 5, guided submission/project preparation and example inspection 15, prepare or improve the summative report Rmd 15, extracted-ZIP practice 15. Second 50: individual report/app work and support 35, coverage and reflection check 10, close 5. The report activity produces a saved Rmd and a rendered draft with at least one static figure; all four plot types are planned, not necessarily completed in class.

The teaching ZIP includes guides and briefs and must not be submitted wholesale. The assessment file set must contain exactly one Rmd report plus rendered HTML (or justified PDF), the Rproj, separate app, data/supporting files, package setup and version information, anonymity checks and the required declaration. Consult assessment-briefs/ for authoritative wording.

Portfolio resource slides are references, not additional teaching tasks. Signpost them during the closing review and leave the links available in the HTML session guide. The submission walkthrough explicitly starts at project creation/checking and includes the official NOW AI declaration.

Open with the five-minute plan for four different static plot types and at least two app views. Static figure questions, interpretation and design reasoning explicitly build on formative feedback; the dashboard does not replace these. Continue the draft during support time; retain the app as a separate source.
