# Week 10: Reproduce and review your portfolio

Core material: a short slide set, `01_reproduce_and_review_your_portfolio.Rmd` (Knit first), and submission-example/, a runnable project with one report Rmd, four example static plot types, bibliography, data, and separate `app/app.R`.

Students use their own project for the extracted-ZIP exercise if ready, or practise with the example. The complete example is a reproducibility aid, a teaching example rather than a model assessment answer.

The report reads data/ from its project root; the app reads ../data/ from its app folder. Test both in a fresh extracted project. Report setup uses tidyverse and bookdown::html_document2; the app uses shiny and tidyverse.

First 50 minutes: requirements/structure 10, run the example and trace paths/packages 10, extracted-ZIP exercise 20, identify remaining issues 10. Second 50: individual work/support 35, coverage and reflection check 10, close 5.

The teaching ZIP includes guides and briefs and must not be submitted wholesale. The assessment file set must contain exactly one Rmd report plus rendered HTML (or justified PDF), the Rproj, separate app, data/supporting files, package setup and version information, anonymity checks and the required declaration. Consult assessment-briefs/ for authoritative wording.
