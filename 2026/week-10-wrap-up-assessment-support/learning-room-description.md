# Week 10: Wrap-up and assessment support

This week is for consolidation and assessment support. We will review expectations for the portfolio, discuss common issues, and use the session to support final planning and troubleshooting.

The focus is on making sure that your static visualisations, interactive dashboard, data files, code, rendered output, and written explanation are organised clearly and can be submitted as a coherent portfolio.

By the end of Week 10, you should be able to:

- check your portfolio against the assessment requirements,
- identify missing files or reproducibility problems,
- improve the organisation of your submission folder,
- explain how your visualisation choices relate to the data and task,
- plan any remaining work before submission.

## Before the practical work: RStudio Project and weekly files

All practical files should be stored inside your module RStudio Project folder. Do not work inside the zip file.

If you have not created an RStudio Project for this module yet:

1. Open RStudio.
2. Go to **File > New Project...**.
3. Choose **New Directory**.
4. Choose **New Project**.
5. Give the project a clear name, for example `psyc40940-visdata`.
6. Choose a sensible location on your computer.
7. Click **Create Project**.

Then download the Week 10 zip folder from this week's section in the NOW Learning Room, unzip it, and move the contents into your module RStudio Project folder. Keep the `.Rmd` files or app files together with any `data` folder and supporting files.
