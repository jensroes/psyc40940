# Week 4: Major visualisation tools

This week is about choosing visualisation tools deliberately. We will not try to memorise every chart type. Instead, we will ask what question a plot answers, what it reveals clearly, and what it hides or makes difficult to compare.

The session links back to the Week 2 principles: show the data and variation, make comparisons easy, avoid misleading summaries, and label plots clearly. We will apply these principles to univariate distributions, bivariate relationships, and group comparisons.

The practical work uses selected parts of the weekly RMarkdown files. The data-wrangling file is homework/reference: this module is not primarily about data wrangling, but the examples will help you recognise when data need to be reshaped or prepared for visualisation.

By the end of Week 4, you should be able to:

- choose a plot type based on the question and variable types,
- explain what different plot types reveal and hide,
- use common `ggplot2` geometries for distributions, relationships, and group comparisons,
- recognise why summary-only plots, such as bar plots with error bars, can be misleading,
- describe how data need to be structured for common geoms,
- create visualisations that show distributions and individual observations more clearly.
