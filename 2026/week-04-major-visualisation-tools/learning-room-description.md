# Week 4: Major visualisation tools

This week focuses on major visualisation types and the kinds of data questions they support. We will look at univariate distributions, bivariate relationships, group comparisons, and common alternatives to less informative plots.

The practical work also includes a short crash course in data wrangling so that you can prepare data for visualisation.

By the end of Week 4, you should be able to:

- choose suitable plot types for univariate, bivariate, and grouped data,
- use common `ggplot2` geometries for different visualisation tasks,
- recognise limitations of common plot types such as bar plots for group comparisons,
- prepare data for plotting using basic wrangling functions,
- create visualisations that show distributions and individual observations more clearly.
