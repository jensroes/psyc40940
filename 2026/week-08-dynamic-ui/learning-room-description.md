# Week 8: Dynamic UI

This week focuses on dynamic user interfaces in Shiny. We will separate cases where a static set of controls is enough from cases where inputs need to update or be generated based on previous user choices.

The practical work introduces dependent filters and generated UI elements that make dashboards more flexible while keeping the app understandable.

By the end of Week 8, you should be able to:

- explain when static UI is preferable and when dynamic UI is useful,
- update existing inputs based on user choices,
- use generated UI elements where appropriate,
- build simple dependent-filter patterns,
- keep dynamic apps clear and manageable.

## Before the practical work: RStudio Project and weekly files

All practical files should be stored inside your module RStudio Project folder. Do not work inside the zip file.

If you have not created an RStudio Project for this module yet:

1. Open RStudio.
2. Go to **File > New Project...**.
3. Choose **New Directory**.
4. Choose **New Project**.
5. Give the project a clear name, for example `psyc40940-visdata`.
6. Choose a sensible location on your computer.
7. Click **Create Project**.

Then download the Week 8 zip folder from this week's section in the NOW Learning Room, unzip it, and move the contents into your module RStudio Project folder. Keep the `.Rmd` files or app files together with any `data` folder and supporting files.
