# 2026 Session Folders

Each teaching week has a self-contained folder with root-level slide decks, exercises, data, graphics, and supporting files needed for that session.

| Week | Folder | Contents |
|---|---|---|
| 1 | `week-01-introduction` | Module introduction, R/RStudio/RMarkdown introduction |
| 2 | `week-02-foundations` | Foundations of data visualisation and ggplot2 exercises |
| 3 | `week-03-grammar-of-graphics` | Grammar of graphics slides and exercises |
| 4 | `week-04-major-visualisation-tools` | Visualisation types, group comparisons, data wrangling |
| 5 | `week-05-customising-visualisations` | Labels, colours, themes, and export |
| 6 | `week-06-shiny-basics-reactivity` | Shiny basics, inputs/outputs, reactive expressions |
| 7 | `week-07-layout-observers` | Layouts, tabs, buttons, observers |
| 8 | `week-08-dynamic-ui` | Dynamic UI, update functions, `uiOutput()`, `renderUI()` |
| 9 | `week-09-dashboard-workshop` | Interactive dashboards with Plotly, deployment options, and assessment-style checks |
| 10 | `week-10-wrap-up-assessment-support` | Assessment support and final project checks |

The older source-style folders are retained in `_source/` as working sources. The `week-*` folders are the Learning Room-facing structure. Slide decks are stored at the week-folder root and share a single `slides.css` file per week.
