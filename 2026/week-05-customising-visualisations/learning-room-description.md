# Week 5: Customising visualisations

This week focuses on improving the clarity and presentation of static visualisations. We will work with labels, legends, colours, facets, themes, and saving plots for use in reports or assessment work.

The session links customisation choices to effective communication: plots should be readable, interpretable, and suitable for the intended audience.

By the end of Week 5, you should be able to:

- improve plot labels using `labs()`,
- customise legends, colours, and facet labels,
- apply and modify `ggplot2` themes,
- make design choices that improve clarity rather than adding unnecessary decoration,
- save plots for use in reports or portfolio work.
