# Week 8: Tabs and reliable controls

This week we organise a dashboard into tabs and make its controls reliable. We continue with the participant reaction-time data from Weeks 6 and 7, so the focus is on navigation, shared filtering, and useful feedback.

By the end you should be able to build tabs, choose single- or multiple-group controls, filter a numeric range, and explain an empty selection with a helpful message.

Unzip the whole Week 8 folder into your existing project, keeping scripts beside data/. Open `01_tabs_and_reliable_controls.Rmd` and Knit it first. Read the HTML guide; edit `starter_app.R` for the tab exercise and `controls_app.R` for filtering and feedback. Use Run App for the scripts. No typing along with live coding is required.

The core app has two tabs and two plots. A third summary tab is optional. The assessment allows up to three tabs; it does not require three. Completed reference code is introduced at the end of the guide.

After class, read Mastering Shiny [section 6.3.1](https://mastering-shiny.org/action-layout.html#tabsets) and [section 8.1.4](https://mastering-shiny.org/action-feedback.html#validate-output). Next week we try Plotly and adapt the dashboard pattern to another behavioural dataset.
