# Week 8: Dynamic UI

This week focuses on dynamic user interfaces in Shiny. We will separate cases where a static set of controls is enough from cases where inputs need to update or be generated based on previous user choices.

The practical work introduces dependent filters and generated UI elements that make dashboards more flexible while keeping the app understandable.

By the end of Week 8, you should be able to:

- explain when static UI is preferable and when dynamic UI is useful,
- update existing inputs based on user choices,
- use generated UI elements where appropriate,
- build simple dependent-filter patterns,
- keep dynamic apps clear and manageable.
