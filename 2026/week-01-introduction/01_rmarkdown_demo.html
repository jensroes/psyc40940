Aim

This document demonstrates the main RMarkdown features you will need in this module:

  • section headings,
  • R code chunks,
  • inline R code,
  • loading packages and data,
  • rendering tables and figures,
  • cross-referencing tables and figures,
  • citing a source from a .bib file,
  • rendering the document to HTML.

RMarkdown is useful because it keeps text, code, results, and figures in one reproducible document. This idea is closely related to literate programming (Knuth, 1984) and dynamic documents (Xie, 2017).

Install Packages

RStudio includes Pandoc, which helps render RMarkdown files. The packages used in this document are separate R packages.

Only run this chunk if a package is missing. The chunk uses eval=FALSE, so the code is shown in the rendered HTML but is not run when the document renders.

# This installs missing packages as a one-time setup step.
# eval=FALSE means this code is shown, but not run when knitting.
# Packages do not need to be installed every time the file is rendered.
install.packages(c("knitr", "rmarkdown", "bookdown"))

Load Data

We will use the blomkvist.csv dataset. These data come from a study on reaction time and ageing using the Nintendo Wii Balance Board (Blomkvist et al., 2017). The data are stored in the local data folder for this week.

# Read the CSV file and store it in an object called blomkvist.
blomkvist <- read_csv("data/blomkvist.csv")

The dataset contains 267 rows and 10 columns. Inline R code is useful when values should update automatically if the data change.

Prepare Data

Here we keep a few variables and remove missing reaction-time values.

# Keep only the variables used in this short report.
selected_data <- select(
  blomkvist,
  id,
  sex,
  age,
  smoker,
  rt_hand_d,
  rt_hand_nd
)

# Remove rows with missing values in either reaction-time variable.
plot_data <- drop_na(selected_data, rt_hand_d, rt_hand_nd)

After removing missing values, the plotting dataset contains 266 rows.

Create a Figure

Figure 1 shows the relationship between reaction times for the dominant and non-dominant hand. The plot is included directly from the R code chunk.

# Start with the data and define the variables used in the plot.
ggplot(plot_data, aes(x = rt_hand_d, y = rt_hand_nd, colour = smoker)) +
  geom_point(alpha = 0.75) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    x = "Dominant hand reaction time",
    y = "Non-dominant hand reaction time",
    colour = "Smoking status"
  ) +
  theme_minimal()

Figure 1: Reaction times for dominant and non-dominant hand responses.

Create a Summary Table

Table 2 summarises the dominant-hand reaction times by smoking status.

# Calculate descriptive statistics for each smoking-status group.
summary_table <- summarise(
  plot_data,
  mean_rt = mean(rt_hand_d),
  sd_rt = sd(rt_hand_d),
  n = n(),
  .by = smoker
)

# Put the table rows into a predictable order.
summary_table <- arrange(summary_table, smoker)

# Render the summary data frame as a table in the HTML output.
kable(
  summary_table,
  digits = 1,
  caption = "Dominant-hand reaction time by smoking status."
)

Interpretation

The average dominant-hand reaction time in the cleaned dataset is 639 ms. When writing up visualisations, combine code-generated values with a short explanation of what the plot or table shows.
