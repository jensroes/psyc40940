# Week 1: Module overview and introduction to RMarkdown

In Week 1, we will introduce the module, the teaching approach, and the assessment. The first part of the session, `part-1-introduction`, focuses on how the module works: who is teaching the module, what the module is about, the learning outcomes, the weekly schedule, the portfolio assessment, formative assessment, dataset support, expectations for engagement, and recommended reading.

The second part of the session, `part-2-rmarkdown`, begins the practical work for the module. You will create or use an RStudio Project, download the Week 1 materials, and render an RMarkdown document to HTML. We use RMarkdown because it allows us to combine text, R code, tables, figures, citations, references, and rendered output in one reproducible analysis document.

By the end of Week 1, you should be able to:

- understand the module structure, assessment format, and expectations for engagement,
- know where to find support for dataset choice and assessment preparation,
- organise the Week 1 files inside your module RStudio Project,
- open and render an RMarkdown file to HTML,
- recognise the main parts of an `.Rmd` file: YAML, Markdown text, R code chunks, inline R code, citations, and references,
- load packages and data in an RMarkdown document,
- create a simple table and figure,
- use basic cross-references for tables and figures,
- cite a source using a BibTeX entry in `references.bib`.

## Before the practical work: RStudio Project and Week 1 files

All practical files should be stored inside your module RStudio Project folder. Do not work inside the zip file.

If you have not created an RStudio Project for this module yet:

1. Open RStudio.
2. Go to **File > New Project...**.
3. Choose **New Directory**.
4. Choose **New Project**.
5. Give the project a clear name, for example `psyc40940-visdata`.
6. Choose a sensible location on your computer.
7. Click **Create Project**.

Then download the Week 1 zip folder from the Week 1 section in the NOW Learning Room, unzip it, and move the contents into your module RStudio Project folder. Keep the `.Rmd` files, `data` folder, bibliography file, and citation style file together. The slides are provided separately in the Learning Room.
